# Blurry Brawlers

A retro pixel-art side-scrolling beat 'em up inspired by Double Dragon, featuring Luke & Nate from the Blurry Creatures podcast.

## How to Run

1. Open `index.html` in a modern browser (Chrome/Firefox/Edge recommended)
2. Or use VS Code + Live Server extension for better development

## Project Structure

See the organized folders for scenes, assets, and utilities.
